# golpe-shop
GOLPE Golf Equipment Online Store

GOLPE(골페) 골프용품 전문 쇼핑몰의 워드프레스 커스텀 테마 저장소입니다.
블랙 & 화이트 기반의 프리미엄 미니멀 디자인이며, WooCommerce와 함께 사용하도록 설계했습니다.

---

## 1. 폴더 구조

```
golpe-shop/
├─ README.md

└─ wp-content/
   └─ themes/
      └─ golpe/                    ← 워드프레스 테마 폴더 (이 폴더를 사이트에 넣습니다)
         ├─ style.css              ← 테마 정보
         ├─ functions.php          ← 기능 파일 불러오기
         ├─ screenshot.png         ← 관리자 테마 목록에 보이는 미리보기
         ├─ header.php / footer.php
         ├─ front-page.php         ← 메인 홈페이지
         ├─ index.php / page.php / single.php / 404.php / searchform.php
         ├─ inc/
         │  ├─ setup.php           ← 메뉴, 로고, 썸네일 등 기본 기능
         │  ├─ enqueue.php         ← CSS / JS 불러오기
         │  ├─ template-tags.php   ← 아이콘, 링크 도우미 함수
         │  ├─ categories.php      ← 골프백 / 골프웨어 / 액세서리 카테고리 정의
         │  ├─ customizer.php      ← 관리자 화면에서 문구·이미지·사업자 정보 수정
         │  ├─ purchase-agency.php ← 해외구매대행 공통 설정·안내 문구
         │  ├─ woocommerce.php     ← WooCommerce 활성화 시에만 동작하는 연동 코드
         │  └─ woocommerce-agency.php ← 구매대행 유의사항·결제 확인·개인통관고유부호
         ├─ page-templates/
         │  └─ purchase-guide.php  ← '구매대행 이용 안내' 페이지 템플릿
         ├─ template-parts/
         │  ├─ home/               ← 메인 화면 섹션 (배너, 카테고리, 신상품 등)
         │  ├─ content.php
         │  └─ content-none.php
         └─ assets/
            ├─ css/main.css        ← 전체 디자인
            ├─ css/woocommerce.css ← 쇼핑(상품·장바구니·결제) 화면 디자인
            └─ js/main.js          ← 모바일 메뉴, 검색창
```

## 2. 로컬(내 컴퓨터) 개발 환경 설치 — Windows + Local

> 실제 운영 사이트가 아니라 **내 컴퓨터의 테스트 사이트**에서 먼저 확인합니다.

### 2-1. Local에서 워드프레스 사이트 만들기
1. **Local** 프로그램을 실행합니다.
2. 왼쪽 아래 **+ (Create a new site)** → **Create a new site** → Continue
3. 사이트 이름: `golpe` 입력 → Continue
4. 환경: **Preferred** 선택 → Continue
5. 관리자 아이디·비밀번호·이메일 입력 → **Add Site**
   - 이 비밀번호는 GitHub나 다른 곳에 올리지 마세요.
6. 설치가 끝나면 **WP Admin** 버튼으로 관리자 화면에 들어갈 수 있습니다.

### 2-2. 테마 넣기
1. Local에서 사이트 이름 오른쪽의 **Go to site folder** 를 누릅니다.
2. `app\public\wp-content\themes` 폴더로 이동합니다.
   - 보통 경로: `C:\Users\내이름\Local Sites\golpe\app\public\wp-content\themes`
3. 이 저장소의 `wp-content\themes\golpe` 폴더를 위 `themes` 폴더 안에 **복사**합니다.
   - GitHub 사용법이 익숙해지면 복사 대신 저장소를 직접 연결하는 방법(아래 5번)을 사용하세요.
4. 관리자 화면 → **외모 → 테마** → **GOLPE** → **활성화**

### 2-3. WooCommerce 설치 (쇼핑 기능)
1. 관리자 화면 → **플러그인 → 새로 추가**
2. `WooCommerce` 검색 → **지금 설치** → **활성화**
3. 설정 마법사는 일단 건너뛰어도 됩니다. (나중에 결제·배송 설정)
   - 통화는 **WooCommerce → 설정 → 일반 → 통화: 대한민국 원(₩)** 으로 맞춰 주세요.

### 2-4. 상품 카테고리 만들기
**상품 → 카테고리** 에서 아래 **슬러그**(영문 주소)로 만들면 메인 화면·메뉴와 자동으로 연결됩니다.
(만들지 않아도 화면은 정상 표시되며, 링크는 전체상품 페이지로 연결됩니다.)

| 이름 | 슬러그 | 상위 카테고리 |
|---|---|---|
| 골프백 | `golf-bags` | 없음 |
| 캐디백 | `caddie-bags` | 골프백 |
| 스탠드백 | `stand-bags` | 골프백 |
| 보스턴백 | `boston-bags` | 골프백 |
| 골프웨어 | `golf-wear` | 없음 |
| 의류 | `apparel` | 골프웨어 |
| 모자 | `caps` | 골프웨어 |
| 신발 | `shoes` | 골프웨어 |
| 액세서리 | `accessories` | 없음 |
| 파우치 | `pouches` | 액세서리 |
| 골프 액세서리 | `golf-accessories` | 액세서리 |
| 기타 용품 | `etc` | 액세서리 |

- 카테고리 편집 화면의 **썸네일** 이미지를 넣으면 메인 카테고리 타일에 사진이 표시됩니다. (세로형 3:4 권장)
- 카테고리 구성은 `inc/categories.php` 한 곳에서 관리합니다.

### 2-5. 화면 문구·이미지 바꾸기 (코드 수정 없이)
**외모 → 사용자 정의하기 → GOLPE 테마 설정**
- **메인 화면**: 상단 공지, 메인 배너 제목·설명·버튼·이미지, 브랜드 소개 문구
- **사업자 정보 (푸터)**: 상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 주소, 고객센터, 이메일
  - 입력한 항목만 푸터에 표시됩니다.

### 2-6. 메뉴 (선택)
**외모 → 메뉴** 에서 메뉴를 만들고 위치를 **메인 메뉴** 로 지정하면 그 메뉴가 사용됩니다.
지정하지 않으면 카테고리 기반 기본 메뉴가 자동으로 표시됩니다.

## 3. 실행(확인) 방법
1. Local에서 사이트 **Start site**
2. **Open site** → 메인 화면 확인
3. 브라우저 창 크기를 줄이거나 개발자 도구(F12)의 모바일 보기로 반응형 확인

## 4. 작업 규칙 (ChatGPT · Claude 공동 작업)
- `main` 브랜치는 직접 수정하지 않습니다.
- Claude는 `claude/작업이름`, ChatGPT는 `chatgpt/작업이름` 브랜치에서 작업하고 PR(변경 요청)로 올립니다.
- 사장님이 PR을 확인·승인한 뒤 `main`에 합칩니다.
- 비밀번호, API 키, 결제 정보, `wp-config.php`, 데이터베이스 파일은 절대 올리지 않습니다. (`.gitignore`로 차단)
- 상품·주문·고객 데이터는 임의로 초기화하지 않습니다.
- 운영 사이트에 반영하기 전에 Local 테스트 사이트에서 먼저 확인합니다.

## 5. (나중에) Local 사이트와 저장소 직접 연결하기
복사 대신 연결하면, 브랜치를 바꿀 때 테스트 사이트에 바로 반영됩니다.
GitHub Desktop 설치가 필요하므로, 진행 전에 단계별로 다시 안내합니다.

## 6. 해외구매대행 설정

GOLPE는 **중국 현지 골프용품 해외구매대행** 쇼핑몰입니다.
구매대행 관련 안내는 메인 화면, 이용 안내 페이지, 상품 상세, 장바구니, 결제 화면에 공통으로 표시됩니다.

### 6-1. 구매대행 조건 입력
**외모 → 사용자 정의하기 → GOLPE 테마 설정 → 구매대행 안내**
- 구매 국가 (기본: 중국)
- 예상 배송기간 (예: 결제 완료 후 약 7~14 영업일)
- 단순변심 반품 비용 — **실제 반품 비용 범위 내 금액만** 입력 (위약금·창고료 등 추가 비용 금지)
- 고객센터 운영시간
- 개인통관고유부호 보관 기간 (기본 90일) — 법적 보관 의무를 확인한 뒤 정하세요
- '구매대행 이용 안내' 페이지 연결 (아래 6-2에서 만든 페이지 선택)

### 6-2. '구매대행 이용 안내' 페이지 만들기
1. **페이지 → 새 페이지 추가**
2. 제목: `구매대행 이용 안내`
3. 오른쪽 설정의 **템플릿** → `구매대행 이용 안내` 선택 → **공개**
4. 6-1의 '구매대행 이용 안내 페이지'에서 이 페이지를 선택
   - 본문에 내용을 쓰면 안내 섹션 위에 먼저 표시됩니다. 비워 둬도 됩니다.

### 6-3. 결제 · 장바구니 페이지를 "클래식"으로 바꾸기 (필수)
개인통관고유부호 입력, 구매대행 조건 확인 체크박스, 장바구니 안내는 **클래식 방식**에서만 동작합니다.
최신 WooCommerce는 두 페이지를 "블록" 방식으로 만들기 때문에 바꿔 주어야 합니다.
1. **페이지 → 결제(Checkout)** 편집 → 기존 "결제" 블록 삭제 → **숏코드** 블록 추가 → `[woocommerce_checkout]` 입력 → 업데이트
2. **페이지 → 장바구니(Cart)** 편집 → 기존 "장바구니" 블록 삭제 → **숏코드** 블록 추가 → `[woocommerce_cart]` 입력 → 업데이트
- 블록 방식이 남아 있으면 관리자 화면 위쪽에 노란색 경고가 표시됩니다.

### 6-4. 상품별 구매대행 정보 (선택)
**상품 편집 → 상품 데이터 → 일반** 탭 아래쪽
- 구매 국가, 예상 배송기간: 비우면 6-1 기본값 사용
- 가격 구성(현지 상품가+현지 배송비 / 국제배송비 / 구매대행 수수료): 3개 모두 입력하면 상품 상세에 구성표가 표시됩니다. 합계가 판매가와 다르면 관리자에게만 경고가 보입니다.

### 6-5. 개인통관고유부호 보호 (암호화 · 열람 제한 · 자동 삭제)
- 결제 시 필수 입력이며 형식(P + 숫자 12자리)을 확인합니다.
- **암호화 저장**: 데이터베이스에는 암호화된 값과 가린 번호(예: `P*********123`)만 저장됩니다. 평문은 저장하지 않습니다.
- **열람 제한**: 관리자 주문 화면에도 가린 번호가 기본입니다. WooCommerce 관리 권한(관리자 · 상점 관리자)이 있는 사람만 **"보기"** 버튼으로 전체 번호를 볼 수 있고, 열람할 때마다 주문 메모에 "열람: 아이디"가 기록됩니다.
- **고객 화면**: 주문 완료 · 주문 내역에는 가린 번호만 표시됩니다. 이메일에는 포함하지 않습니다.
- **자동 삭제**: 주문이 완료 · 취소 · 환불 · 실패 상태가 되고 보관 기간(6-1, 기본 90일)이 지나면 매일 자동으로 삭제되고 주문 메모에 기록됩니다.
- **개인정보 요청**: 관리자 → 도구 → 개인 데이터 내보내기 / 지우기 에 연동되어 있습니다. (내보내기는 가린 번호만)

#### 전용 암호화 키 설정 (운영 전 필수 권장)
키가 없으면 워드프레스 보안 키로 대신 암호화하며, 관리자 화면에 파란색 안내가 표시됩니다.
1. 아무 곳에서나 길고 무작위한 문자열(64자 이상)을 만듭니다. 예: https://api.wordpress.org/secret-key/1.1/salt/ 에서 나온 값 중 하나
2. 서버의 `wp-config.php` 파일에서 `/* That's all, stop editing! */` 줄 **위에** 아래 한 줄을 추가합니다.
   ```php
   define( 'GOLPE_CUSTOMS_KEY', '여기에-만든-무작위-문자열' );
   ```
3. ⚠️ 이 키는 **GitHub에 올리지 말고**, 안전한 곳에 따로 보관하세요.
4. ⚠️ 키를 추가하거나 바꾸면 **그 전에 저장된 번호는 열 수 없습니다.** 운영 시작 전에 한 번 정해 두고 바꾸지 마세요. (워드프레스 보안 키를 바꿔도 마찬가지)

#### 오픈 전 필수
- **개인정보처리방침에 '개인통관고유부호 수집 목적(수입 통관), 보유 기간, 관세청 · 통관 대행 업체 제공'을 반드시 추가하세요.**

### 6-6. 지키는 원칙 (수정 시에도 유지)
- "반품 불가", "해외상품 환불 불가", "주문 후 취소 불가" 같은 문구를 쓰지 않습니다.
- 상품을 받은 날부터 7일 이내 청약철회 가능, 하자·오배송 시 반품비는 판매자 부담.
- 결제 단계 체크박스는 "조건을 확인했다"는 의미일 뿐, 청약철회·환불 권리를 포기하게 하지 않습니다.
- 법적 안내 문구는 초안입니다. **오픈 전 전문가 또는 공정거래위원회 기준으로 최종 검토하세요.**
